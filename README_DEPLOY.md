# Deploy web EHU
Subir este ZIP a la raíz de `EuskadiOposiciones/upvehuoposicionesbateria` en `main`.

Incluye:
- landing de app con 4 capturas completas,
- vídeo lazy con youtube-nocookie,
- QR,
- nueva `/administrativo/preguntas-resueltas/` con 20 casos ya documentados,
- CSS corregido para imágenes verticales,
- enlaces UTM,
- PostHog cookieless común,
- sitemap actualizado.

No incluye un mini-test de 10 preguntas porque no se han reconstruido enunciados/opciones sin una fuente canónica publicable.
No fija precio/modalidad textual de EHU hasta verificar el modelo comercial vigente.
